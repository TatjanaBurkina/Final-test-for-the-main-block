# 🏁 Final Assessment Project (Итоговая проверочная работа)

Итоговый проект, содержащий практические задачи на языке **C# (.NET)**, блок-схему алгоритма, а также подробную текстовую документацию и описание решения.

---

## 📂 Структура проекта

Репозиторий включает в себя следующие компоненты:
* **`2. Нарисовать блок-схему/`** — графическое представление алгоритма (файл `Контрольная работа.drawio`).
* **`3. Текст.md/`** — текстовые файлы с описанием условий, хода решения и пояснениями (`Description.md`, `Описание.md`).
* **`Program.cs`** — основной исходный код с реализацией алгоритмов задач на C#.
* **`Task 1.csproj`, `Task 2.csproj`, `Task 3.csproj`** — файлы конфигурации проектов .NET для отдельных задач.

---

## 🛠 Технологии и инструменты
* **Язык программирования:** C# (.NET)
* **Инструменты проектирования:** Draw.io (для блок-схем)
* **Документация:** Markdown

---
